# راهنمای نسخه ۸

این نسخه بر پایه ظاهر نسخه ۶ ساخته شده و پنل انتخاب طراحی نسخه ۷ را به آن اضافه می‌کند. از آیکون‌های سمت چپ برای انتخاب رنگ، فونت، چیدمان، جزئیات و گزینه‌های پیشرفته استفاده کنید.

ظاهر انتخابی در مرورگر ذخیره می‌شود. در بخش Save می‌توانید گزینه‌های A و B را ذخیره کنید، لینک انتخاب را کپی کنید، پیش‌نمایش موبایل را ببینید و تنظیمات JSON بگیرید.

برای انتشار: فایل ZIP را استخراج کنید و **محتویات آن** را در ریشه مخزن `alirezajalaliut8` بارگذاری کنید. سپس GitHub Pages را از شاخه main و پوشه /(root) فعال کنید.

آدرس: https://alirezajalaliut.github.io/alirezajalaliut8/

در Pages CMS، قسمت Design Defaults انتخاب پیش‌فرض برای بازدیدکنندگان جدید را تعیین می‌کند. بخش‌های خالی علمی عامدانه بدون اطلاعات ساختگی باقی مانده‌اند.
